## 不做,以及为什么

写在这里是为了防止下一轮"顺手补上":

- **社区声誉值 / 活动满意度** — 这个系统永远不会产生这两个数(没有评分入口)。
- **主办方奖金池** — 与"主办方从头到尾碰不到一分钱"直接冲突,那是整个产品的立身之本。
- **通知铃铛** — 没有通知系统,挂个铃铛点了没反应。
- **四种验证方式** — 实际只有两种:信标签到 + 同伴互证。地理位置可伪造,信标存在的
  理由正是替代它。
- **活动封面图上传** — 没有图床。现在按活动 id 生成图案。
- **USD 折算 / 较上月** — 这两个**要留着**,将来会有(接价格源、攒够历史),
  现在显示 `—` 而不是 0。`—` 是"还不知道",0 是一个断言。
