| 标准 | 实测 |
|---|---|
| 表情太空、没有"在找东西"的感觉 | **不成立**。有完整表演节拍:第 8–56 帧盯着手机 → **第 80 帧闭眼呼一口气** → **第 104 帧转头看向镜头、眉毛微抬**。正是"挑活动、有点无聊、若有所思" |
| 口型/动作不适合加短台词 | **不成立**。这句是自言自语/内心外化,不需要对口型;而第 104 帧那个"转头"正是独白最自然的落点 |
| 人物连续性有问题 | **不成立**。与 a5/a6 同一个人、同一件浅灰 hoodie、同一发型 |

**另有一条结构性理由:** a5 是用 a2 的**尾帧**生成的,a6 又接 a5 的尾帧。
重做 a2 会让 a5 失去首帧依据,连带 a6 一起作废 —— **一条重做变三条**。

工具:`edge-tts`,在 `~/miniconda3/envs/interview/bin/edge-tts`。

| **声音类型** | 男声,25–35 岁质感。不要中年播音腔 |

### D2 · Participant Voice

| | |
|---|---|
| **画面依据** | a2/a5/a6 里是个**年轻女性**,短棕发、浅灰 hoodie |
| **声音类型** | 女声,20–28 岁质感。要"躺在沙发上随口说"的松弛度 |

### D3 · Narrator Voice

本轮只备短句,不录整片。

> "PeerProof helps organizers find the right people."
> "And helps people find events worth showing up for."
> "Proof comes from peers."

| | |
|---|---|
| **声音类型** | 中性偏低,**不要**和 Organizer 同一把 —— 旁白和剧中人必须听得出是两个人 |
| **候选** | `en-GB-RyanNeural`(英音,克制有距离感,**推荐**) / `en-US-BrianNeural` |
| **语气关键词** | 克制、笃定、不推销。这个产品的立论是"你自己能核实",旁白也该是这个态度 |
| **语速** | `--rate=-2%` |
| **停顿** | 三句**分别生成三个文件**,不要一口气念完。剪辑时各自对位,中间的空当由画面决定 |
| **时长** | 三句连读 8.6s(Brian) / 9.8s(Ryan) |

### D4 · 能不能用同一个模型做完

**能。** 三类声音全部用 `edge-tts` 一个模型就够,换 voice 名即可 —— 音质基底一致,不会出现"某一句忽然换了录音棚"。

但**三把声音必须互不相同**:

- Organizer = 男声(Andrew)
- Participant = 女声(Ava)
- Narrator = 英音男声(Ryan)

Organizer 和 Narrator 都是男声,所以刻意让 Narrator 用**英音**拉开距离。
如果试听后觉得两个男声还是像,就把 Narrator 换成女声 `en-GB-SoniaNeural`。

**这条是本机的硬规矩**:同一部片里每个人物音色必须区分,同一人物跨镜音色必须固定。

生成命令:

```bash
~/miniconda3/envs/interview/bin/edge-tts \
  --voice en-US-AvaNeural --rate=-8% \
  --text "Where can I find something fun... and maybe earn something for showing up?" \
  --write-media 出片/配音/participant_01.mp3
```

## E. 字幕规范

所有**真正说出口**的英文台词都上英文字幕:Organizer 开场句、Participant 开场句、Narrator 关键解释句。

| | |
|---|---|
| 颜色 | 纯白 `#ffffff` |
| 位置 | 底部居中,距底边 8% 画面高 |
| 行数 | **两行以内** |
| 字号 | 画面高的 4.2%(1080p 约 45px)。不要更大 |
| 描边 | 1.5px 半透明黑,**不要**黑底色块 —— 色块会挡住画面 |
| 避让 | 录屏段落里字幕**必须避开真实 UI 的关键区域**(活动状态卡、按钮、二维码)。挡不住就把那句话挪到前后的空镜上 |
| 风格 | 统一、克制,不做逐字弹出、不做花哨入场 |

ffmpeg 烧字幕参考:

```
force_style='FontName=Inter,FontSize=45,PrimaryColour=&Hffffff,
             Outline=1.5,OutlineColour=&H80000000,BorderStyle=1,
             Alignment=2,MarginV=86'
```

## F. 本轮 H3 不做的事(范围收紧)

不生成:Logo 动画、真实网页、Event UI、二维码、Monad 交易界面、Proof Graph、
结算数字、片尾字卡、任何可读文字。

这些全部由**真实录屏 + 后期**完成。H3 的生成额度不花在文字和 UI 上。

**口型**:需要说话的镜头允许"轻微说话状态/自言自语口型",
但画面里**不许出现任何可读字幕、对白文字、弹幕或 UI 文案**。
H3 只负责"人像是在说话",真正的配音和字幕全部后期。
